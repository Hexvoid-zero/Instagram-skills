## Quality bar

- Specific to this account. Swap the name and it should not still read true
  for a competitor.
- Every tactic has a metric and a review date.
- Hours add up. If the plan needs 20 hours and the owner has 6, cut the plan.
- No invented benchmarks. Use the account's own median as the yardstick.
- Risks name something real: algorithm change, burnout, a single-channel
  dependency, platform policy.
