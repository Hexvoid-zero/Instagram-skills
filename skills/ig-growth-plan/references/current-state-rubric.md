# Current-State Rubric

Score each row 0 to 5 from real evidence: the profile, the last 30 posts and
the insights the user shares. Write one line of evidence per row. Mark
"unknown" instead of guessing.

| # | Area | 0 | 3 | 5 |
|---|------|---|---|---|
| 1 | Positioning | No clear niche | Niche stated, hard to repeat | Specific audience and promise, visible in every post |
| 2 | Profile | Default bio, no link | Clear bio, one link | Bio, pins, Highlights and link form a funnel |
| 3 | Content pillars | Random topics | 2 to 3 pillars, loosely held | Named pillars and a signature series |
| 4 | Hooks | Generic openings | Some strong hooks | A hook system tied to the swipe file |
| 5 | Format mix | One format only | Reels and carousels | Mix matched to goal, with repurposing |
| 6 | Consistency | Irregular | Mostly weekly | Fixed cadence the owner can sustain |
| 7 | Community | Comments unanswered | Replies when remembered | Daily reply sweep and proactive commenting |
| 8 | DM flow | None | Manual replies | Keywords, welcome message, follow-up |
| 9 | Conversion tracking | None | Link clicks only | UTM per post, DM outcomes logged |
| 10 | Offer | Unclear | Defined but not shown | Clear ladder and proof in content |
| 11 | Social proof | None | Occasional testimonial | Proof built into pins, Highlights, posts |
| 12 | Collabs | None | Occasional | A pipeline with a cadence |
| 13 | Paid | None | Boosts only | Structured tests, retargeting, tracking |
| 14 | Measurement | None | Looks at likes | Weekly review, monthly post-mortem |
| 15 | Learning | No record | Informal | Learnings table, tests with hypotheses |
| 16 | Brand and voice | Inconsistent | Mostly consistent | Documented voice, consistent visuals |
| 17 | Risk | Unaware | Aware | Policy, disclosure and crisis plan in place |

## Scoring

- Total out of 85. Under 35 means build foundations before scaling. 35 to 60
  means optimize the weakest stage. Over 60 means scale and test.
- The three lowest rows become the first 30 days of the roadmap.
- Re-score at day 90.
