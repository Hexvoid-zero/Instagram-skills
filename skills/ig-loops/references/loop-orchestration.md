# Loop Orchestration and Rollout

Loops compose into an operating system for the account. This covers how they
fit together and the order to adopt them, so you never build them all at once.

## The system view

```
SENSING        weekly review · early-performance check · niche watch
                  │  (see what changed; trust the numbers first)
                  ▼
DIAGNOSTIC     monthly post-mortem · series tracker · ad fatigue ·
               profile rot check
                  │  (decide what to do about it)
                  ▼
ACTION         weekly plan · repurpose · comment sweep · DM triage ·
               boost candidates · creative drop
                  │  (mostly human-checkpointed)
                  ▼
LEARNING       campaign post-mortem · Learnings rows in brand.md
                  └──────────────► feeds back into SENSING and DIAGNOSTIC
```

Connective tissue:

- **The weekly review is the router.** It reads top-line movement and dispatches
  each mover to the loop that owns it.
- **The weekly plan is the sink.** Ideas, repurposes, boosts and series
  decisions end up in `plan.md`, so there is one place to look.
- **The post-mortem closes the loop.** Learnings that hold are proposed for the
  Learnings table in `brand.md`, where every ig skill reads them.
- **Comments and DMs are a source.** The language they hold feeds hooks, ad
  angles and FAQ content.

Avoid duplicate ownership. When two loops could act on the same signal, one
owns the action and the other flags. A boost candidate belongs to the boost
loop, not the repurpose loop.

## Rollout path (adopt in this order)

Add a loop only when the previous ones run and earn their keep.

**Stage 0, see the board.** Weekly plan (1), weekly review (4). You cannot run
loops on guesswork.

**Stage 1, learn from what you post.** Monthly post-mortem (3),
early-performance check (13). Evidence before more output.

**Stage 2, protect conversion.** Comment sweep (9), DM triage (10), lead
follow-up (12), profile rot check (18). Capture the attention you already get.

**Stage 3, feed the engine.** Swipe refresh (2), hook bank refill (6),
top-post repurpose (5), series tracker (7), pillar-account commenting (11).

**Stage 4, add paid.** Boost candidate (14), weekly ads check (16), ad fatigue
(15), retargeting hygiene (17), daily creative drop (8). Only once organic has
found something worth amplifying.

**Stage 5, compounding.** Collab pipeline (20), niche watch (19), campaign
post-mortem (22), crisis watch (21).

## Rollout rules

- **One at a time.** Prove a loop earns its keep before adding the next.
- **Foundation before growth.** Planning and measurement before volume.
- **Cap the total.** More loops than you can review means vanity loops. Retire
  the ones nobody acts on.
- **Re-audit quarterly.** Recalibrate thresholds, kill dead loops, promote the
  ones that consistently drive action.
